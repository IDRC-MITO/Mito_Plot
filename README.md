# Mito_Plot
Variant visualization of mitochondrial DNA heteroplasmy across large-scale samples

# Mitochondrial Heteroplasmy Analysis and Visualization

This repository contains scripts to calculate mitochondrial DNA heteroplasmy from VCF files and visualize the results in interactive circular plots.

In addition to the original 2D interactive plots, which allow free zooming and panning, the tool now supports an interactive Dash/Plotly-based 3D circular genome visualization for mitochondrial DNA (mtDNA) heteroplasmy across samples.

This enhancement enables detailed visualization of aggregated variants and MAF values across large cohorts, providing better insight into complex heteroplasmy patterns that were difficult to explore with previous 2D-only visualizations.

This tool maps variant positions onto the human mitochondrial genome (rCRS), encoding MAF radially and the number of samples vertically.



## Features

- 3D circular visualization of mtDNA heteroplasmy
- rCRS-based gene annotation
- Radial encoding of MAF values
- Vertical encoding of the number of samples
- Interactive gene-level filtering (Dash UI)
- Hover-based inspection of variant details

## Files

- `step1.py`:
  
  Processes multiple mitochondrial VCF files (*.vcf) from individual samples and calculates MAF values at each variant position. Outputs a merged TSV file summarizing MAF values per sample and genomic position.

- `step2.py`:
   
  Loads the merged TSV generated by step1.py and creates an interactive Plotly-based 2D circular plot showing MAF values by genomic position, with mitochondrial gene regions annotated. This script supports zooming and panning for detailed inspection.

- `step3.py`:
  
  Loads the merged TSV generated by step1.py and creates an interactive 3D circular plot representing MAF values across samples. The plot places samples along the Z-axis with adjustable height compression to improve visualization of large cohorts, and mitochondrial gene regions are annotated in 3D.

- `step4.py`:
  
  Loads the merged TSV generated by step1.py and visualizes mitochondrial MAF values interactively using a 3D circular line plot. Compared with step3.py, this script emphasizes line-based representation. The Z-axis is scaled by sample count to highlight clustering and accumulation patterns across samples. The plot supports gene-level filtering through a dropdown menu, allowing users to inspect specific mitochondrial regions interactively. Hover information displays MAF values, variant counts, and sample counts for comprehensive cohort-level analysis.

## Usage

1. Prepare a directory containing your mitochondrial VCF files named like `sample1_chrM.vcf`. : python step1.py /path/to/vcf_directory [--output output.tsv]

2. Run step Plotting a 2D Plot:
python step2.py All_YYYMMDD.tsv

3. Run step Plotting a 3D Plot(Dot_Plot):
python step3.py All_YYYMMDD.tsv

4. Run step Plotting a 3D Plot(Line):
python step4.py All_YYYMMDD.tsv

## Input File Specification

The software expects input VCF files generated on the GRCh38 reference genome (VCF v4 format), with the chromosome column (CHROM) labeled as chrM. This is the standard convention for mitochondrial DNA in GRCh38-based VCF data.

Input file format
The input TSV file must follow this structure:

chrM    Position    Ref    Alt    sample1    sample2    ...

Position: mtDNA coordinate (1–16569, rCRS)
Heteroplasmy values may be:
Fractions (0–1)
Percentages (12%)
Numeric values (12 → interpreted as 12%)
